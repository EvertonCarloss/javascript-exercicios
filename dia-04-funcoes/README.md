# Exercícios de JavaScript – Dia 04

Hoje pratiquei **funções em JavaScript**, focando na criação de funções, uso de parâmetros, retorno de valores e aplicação de lógica dentro das funções.

## Conteúdos praticados

- Criação de funções
- Parâmetros
- Return
- Funções com condicionais
- Funções matemáticas simples

## Exercícios realizados

1. Função de saudação
2. Função para mostrar nome
3. Função para somar dois números
4. Função para multiplicação
5. Função para verificar maioridade
6. Função para calcular área de um retângulo
7. Função para calcular o dobro de um número
8. Função para verificar se um número é par ou ímpar
9. Função para identificar o maior número entre dois valores

## Objetivo

Fortalecer a base em JavaScript antes de avançar para bibliotecas e frameworks do ecossistema front-end.
