# Exercícios de JavaScript – Dia 05

Hoje pratiquei **funções em JavaScript**, com foco em melhorar a lógica e a organização do código.

## Conteúdos praticados

- Criação de funções
- Uso de parâmetros e retorno
- Condicionais dentro de funções
- Funções chamando outras funções

## Exercícios realizados

- Calculadora com validação
- Número primo
- Cálculo de média e resultado
- Cálculo de IMC
- Sistema de frete
- Desconto progressivo
- Sistema de aprovação com faltas

## Objetivo

Fortalecer a base em lógica de programação antes de avançar para objetos.
